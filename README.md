# TrustVault
## Secure Document Sharing with a Real Audit Trail

TrustVault is a secure document-sharing web application built using Python and Flask. It helps users share documents with authorized people and maintains an audit trail of important activities.

### Features
- User login and logout
- Secure document upload
- Controlled document sharing
- Grant and revoke document access
- Permission-based document downloads
- Block unauthorized downloads
- Audit trail for login, logout, sharing, revoking, and downloads

### Technologies Used
- Python
- Flask
- HTML
- CSS
- JSON
- Visual Studio Code

### How to Run
1. Install Python.
2. Install Flask using `pip install flask`.
3. Open the project folder in VS Code.
4. Run `python app.py` in the terminal.
5. Open `http://127.0.0.1:5000` in your browser.

### Project Purpose
The purpose of TrustVault is to demonstrate secure document sharing, access control, and activity tracking.
